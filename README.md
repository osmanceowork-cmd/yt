# Ustoz YouTube havolasi

Instagram Direct (Chatplace «25» avtomatikasi) tugmasi shu sahifaga olib keladi. Sahifa telefonda YouTube ilovasini ochadi
(Android: intent, iOS: youtube://), ilova bo'lmasa 2 soniyadan keyin brauzerda ochadi.

- Video: @usmon_dostonov kanalidagi oxirgi uzun video (Shorts'siz). GitHub Action har 30 daqiqada RSS'dan tekshiradi va yangilaydi.
- Aniq video kerak bo'lsa: `?v=<VIDEO_ID>`.
